# Web Summit Lisbon 2026

Volledig programma (10–12 nov 2026, 1091 sessies), opgehaald van websummit.com op 7 nov 2026.

| Bestand | Inhoud |
|---|---|
| `websummit_2026_sessies.xlsx` / `.csv` | Alle sessies: dag, start, eind, stage, track, titel, beschrijving, sprekers, organisaties, host/partner, type, url |
| `websummit_2026_zoekcorpus.txt` | Platte tekst per sessie, voor doorzoeken |
| `websummit_planner.html` | Planner: zoeken, shortlist, serendipity, eigen selectie met overlap- en vrije-tijdweergave (live: https://claude.ai/artifact/DTqRXRQV1ebbU5F8STxEPh) |
| `shortlist_saas_toekomst.md` | Voorstellen rond toekomst van SaaS, rollen/skills en concurrentie |
| `serendipity.md` | Voorstellen buiten dat onderwerp |
| `mijn_programma.md` | Eigen selectie (stand 8 nov) |
| `failures.json` | 4 sessiepagina's die blijvend een 404 gaven |
| `scripts/` | Scraper, verificatie en export |
